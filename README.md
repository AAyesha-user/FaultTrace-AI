# FaultTrace AI

Intermittent Fault Diagnosis in Multi-Agent Systems.

Research-based project implementing and extending spectrum-based fault diagnosis in simulated multi-agent systems.

## Planned modules
- Warehouse simulation
- Autonomous agents
- Fault injection
- Execution history collection
- Spectrum-based diagnosis
- Evaluation
- Recovery and task reassignment

## Research
We are studying published work on intermittent fault diagnosis in multi-agent systems. The original authors and contributions will be acknowledged.

## Stack
Python, FastAPI, NumPy, Pandas, React (planned).
